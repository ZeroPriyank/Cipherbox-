# Cipherbox

A client-side text encryption and decryption tool.

## Features

- AES-256-GCM encryption
- Password-based encryption
- PBKDF2 with SHA-256
- Runs entirely in the browser
- No server required
- No stored encryption keys

## About

Cipherbox is an open-source encryption tool that lets users encrypt and decrypt text locally.

## Security

Cipherbox uses the Web Crypto API for encryption and decryption.
